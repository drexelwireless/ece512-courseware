# Reference-radio assets

`reference-radio-drexel-space.png` is an original image generated for this course with OpenAI's built-in image
generation tool on October 14, 2026. It depicts a blue-and-gold dragon mascot piloting an original space-opera
craft above a stylized Philadelphia campus skyline and transmitting radio waves. The prompt explicitly excluded
franchise characters, vehicles, logos, typography and copied scenes.

The high-contrast 4:3 composition is intentional: `ece512.radio.reference_image` center-crops and downsamples it
for the packet-loss demonstration, where missing packet rows appear as dark horizontal bands.
